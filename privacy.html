Privacy Policy — Charter Uploader

Last updated: 9 August 2026

Charter Uploader is a personal, single-user tool. It is used by its author to upload his own music videos to his own TikTok account as drafts. It is not offered to other users, has no sign-up, and processes no data belonging to anyone else.

What data is accessed

With the permissions granted through TikTok Login, the tool accesses:

  • An access token and refresh token issued by TikTok for the author's own account, used to authorise uploads.
  • Video files that the author selects on his own computer, which are sent to TikTok as drafts.
  • Basic metadata about the author's own posts (post id, publication date, description, view and like counts), if the account inventory feature is used.

Where data is stored

Everything stays on the author's personal computer. Tokens are stored in a local file (tokens.json) readable only by the author's operating system account. Video files and metadata are stored in local folders. There is no server, no database, and no cloud component operated by this tool.

What is not done with the data

  • No data is sold, rented, shared, or disclosed to any third party.
  • No advertising, profiling, tracking, or analytics of any kind.
  • No data about any TikTok user other than the author is collected or processed.
  • Data is transmitted only to TikTok's own official API endpoints.

Retention and deletion

Tokens and files are kept only as long as the author needs them and can be deleted at any time by removing the local files. Access can be revoked at any time from the TikTok app under Settings → Security & permissions → Manage app permissions, which immediately invalidates the tokens.

Children

The tool is not directed at children and is not available to anyone other than its author.

If this policy changes, the updated version will be published at this same address with a new date.
